병행 코덱스1 작업은 CODEX1_PARALLEL_TASKS.md로 분리한다. 전체 목표/최종 릴리스는 아직 미완료다.

## 현재 연결한 경로

- 촬영에서 본체 위쪽과 지정 시작 변형을 선택할 수 있다. 둘 다 확인한 경우만 SWC1 조건을 보낸다.
  기본 촬영의 미확인을 새 조건으로 추정하지 않는다. 워치가 조건 형식 1을 광고해야 새 조건 촬영을 시작한다.
- 저장한 촬영에서 준비 방향 확인으로 진입한다. 직접 관찰한 원본 구간 또는 영상에서 지정한 프레임
  구간을 사람이 표시한다. 영상 확인은 시계 정렬/실제 MP4 프레임 대응/영상·프레임·시계 digest를 검사한다.
  영상 구간의 양 끝은 시계 불확실성만큼 좁혀 2초 센서 구간을 확보한다.
  폰 촬영 ID와 워치 원본 ID는 구분하고 연결 파일을 통해 원본 ID에 라벨을 저장한다.
  사용자가 확인 후 영상만 삭제하면 삭제 전 관측 hash·프레임 대응을 보관해 기존 라벨의 출처를 유지한다.
  실제 이미지가 없는 자료에서 새 영상 라벨은 만들지 않는다.
- 지정 방향·반대 방향의 정지 구간에서 목표 중력 벡터를 맞추고 사용자가 입력한 실험 여유각을 보존한다.
  학습에 쓰지 않은 지정·반대·일상 원본을 실제 준비 게이트로 재생한다. 일상 정지가 목표와 구분되지 않으면 실패다.
- 원본 SHA/기기/사용자/착용/본체 방향/변형/라벨 revision이 같은 후보만 활성 선택할 수 있다.
  활성 선택 시와 새 시도 선택 시 기존 성공 플래그를 믿지 않고 원본/라벨/독립 재생을 다시 확인한다.
- 정상 운동 START/SET/작업 SYNC의 추가 20번 필드로 SDR1 스냅샷을 보낸다. 기존 0~19번은 유지한다.
  폰의 세트/시도 바인딩은 스냅샷과 부재를 고정한다. 끄기·후속 활성화는 다음 새 시도부터 적용된다.
- 워치는 선언 조건과 실제 기기를 비교하고 진행 중/작업 일시정지 상태의 같은 시도 변경을 거절한다.
  영속 runtime과 원본 manifest에 정확한 스냅샷/방향 상태/최초 측정 센서 시각을 기록한다.
  같은 스냅샷의 저장 응답 SHA가 있어야 폰의 명령 outbox가 완료된다. 구형 기본 ACK로 완료하지 않는다.
- 방향 검사에서는 가속도와 자이로 신뢰도 1~3, 가속도 나이 40ms 이하, 샘플 공백 60ms 이하가 필요하다.
  기대 방향에서 연속 2초가 필요하며 다른 방향·신뢰도 미확인·공백에서 준비 시간을 잇지 않는다.
- 워치에서 `방향 확인 없이 직접 시작`을 선택할 수 있다. 정확한 시도에만 적용하며 BYPASSED로 남긴다.
  CONFIRMED도 전체 몸 자세 판정이 아니다. 폰/워치 운동 화면에서 미확인·확인·직접 시작을 구분한다.
- 방향 준비 원본은 보존한다. 준비 통과/직접 시작 후 실제 판정기에 처음 전달한 원래 센서 시각부터
  폰 재분석을 시작한다. 준비만 기록되고 이 경계가 없으면 자동 확정 0회로 만들지 않는다.
- 준비 중 서비스 재생성은 새 연속 2초를 확인한다. 확인/직접 시작 상태는 같은 부팅의 복구·일시정지에서
  유지한다. 부팅 경계에서는 이전 준비 확인과 시각을 재사용하지 않는다.

PAIRED_REFERENCE 촬영에는 작업용 강제 방향 게이트를 적용하지 않는다. 반대·일상 대조 자료도 수집해야 한다.
보류 33종의 일반 작업 시작과 기존 수동 7종은 방향 프로필 선택 대상이 아니다.
