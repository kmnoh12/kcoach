# G12 스쿼트 전신 영상 관측 — 2026-10-15

추가 스쿼트 계약의 소프트웨어 연결이다. 사용자 폰의 MediaPipe 초기화와 실제 스쿼트 관측 성공은 미확인이다.
워치 단독 자동 횟수 정책은 승격하지 않는다. 기존 기본 43종 카탈로그도 바꾸지 않는다.

## 사용자 진입과 자료

측정·보정 목록에 전신 촬영용 스쿼트/백/프런트/고블릿/스미스 항목을 추가했다.
모두 SQUAT 레시피·카메라 관측을 공유하며, 카메라 안내·영상 반복 후보·실시간 관측이 같은 조건을 쓴다.
이 항목들은 촬영 진입점이며 일반 운동 목록에 새 검증 자동 종목을 추가한 것이 아니다.
일반 운동의 스쿼트/추가·커스텀 종목은 원래 수동 정책을 유지한다.

머리·양쪽 어깨/골반/무릎/발목이 보이고 선 자세 후보가 안정되어야 촬영 준비가 된다.
시작 자세 직접 확인도 필요하다. 단순히 사람이 보이거나 서 있다는 이유로 일반 운동 기록을 시작하지 않는다.
영상은 준비 원본도 남긴다. 반복 후보 시간은 움직임 직전 마지막 준비 프레임에서 시작하고 완전 복귀해야 끝난다.
완료 확인 시간은 해당 영상 반복 구간이며 일반 운동의 세션 타이머와 혼동하지 않는다.

## 임시 관측 조건의 한계

CameraMotion.SQUAT_KNEE_FLEXION은 관측 후보용 무릎 160도 준비/110도 이탈, 준비 때 고관절 150도,
영상의 머리→어깨→골반→무릎→발목 순서와 기존 200ms 안정 구간을 사용한다.
이 수치는 최적값/임상 정상 범위/올바른 깊이가 아니다. 부분 동작·가림·누락·누운 영상은 후보를 만들지 않는다.
사용자가 실제 영상을 확인한 시작/전환/복귀가 기준이다. MediaPipe 제안을 자동 정답으로 저장하지 않는다.
스쿼트에 워치의 일괄 2초 방향 확인을 붙이지 않는다.

## 보여주는 관측값

- 내려감/올라감 구간 시간. 사람이 표시한 정지만 빼며 미표시 정지는 0초로 간주하지 않는다.
- 무릎·고관절의 상대 world 관절 추정각 범위. 임상 관절 ROM이나 자세 정확도 점수가 아니다.
- 영상평면 몸통 기울기 변화.
- 골반 영상평면 옆/아래 이동과 복귀 위치 차이. 두 영상 축을 픽셀로 맞추고 첫 몸통 길이로 정규화한다.
  매 프레임 골반 world y는 사용하지 않는다. 고정 카메라/같은 크기·방향/유효 관측만 허용한다.
  실제 3D 이동 높이·중량 이동 속도·가상 IMU 경로의 수직성 점수가 아니다.

CameraSquatAnalyzer/CameraSquatMetrics는 상체 팔꿈치 지표와 분리한다. CalibrationReviewStore는
기존 형식 읽기를 유지하며 cameraSquatMetrics 출처/좌표계/값을 저장한다.
영상만 삭제해도 관절·센서·확인 라벨·관측 지표가 남고 선택 ZIP의 review.json에도 포함된다.
현재 수동 종목에서는 개인 DTW 후보 생성/자동 채택 버튼을 제공하지 않는다. 실제 대응 신호의 별도 연구·승격은 미확인이다.
