# 워치짐 디자인 언어 (2026-10-12)

한 줄 요약: **숫자가 주인공인 어두운 화면.** 장식은 빼고, 운동에서 실제로 나온 숫자(경과일, 볼륨, 반복 수, 템포)를 크게 보여준다. 포인트색은 민트 하나.

## 왜 새로 짜는가

플랫폼 하나(플릭)의 구조만 따라가면 세부 모양까지 닮아 버린다. 그래서 동작 아이디어는 여러 앱에서 가져오고, 모양은 우리 데이터에서 끌어낸다. 복원한 코드와 에셋은 쓰지 않는다.

## 본 앱들에서 가져온 것과 우리 방식

| 본 것 | 어디서 | 우리가 취한 아이디어 | 우리 식 구현 |
|---|---|---|---|
| 세트 줄에 지난번 값이 연하게 붙음 | Hevy | 입력하는 순간 비교 대상이 보이는 것 | 세트 번호 아래에 지난번 값을 작게(별도 열은 두지 않음), 완료하면 줄 전체가 민트 워시로 바뀜 (구현됨) |
| 신기록 순간을 크게 축하 | Fitbod | 기록 갱신을 놓치지 않게 | 세트 완료 때 숫자 한 줄로 알림, 결과 화면에서 갱신 항목 강조 (예정) |
| 몸 그림에 근육별 볼륨 | 짐워크, Fitbod | 어떤 부위를 했는지 한눈에 | 민트 한 색의 농도로 표시 (예정) |
| 한 세트씩 큰 숫자로 보는 집중 화면 | 플랜핏 | 운동 중엔 숫자 하나만 | 워치가 센 반복 수를 실시간으로 크게 (우리만의 강점, 예정) |
| 주간 목표 링/요일 | Fitbod, Gym+ | 이번 주 진행을 바로 확인 | 요일 막대, 높이 = 운동 시간과 세트 수를 합친 부하 |
| 워치 코칭을 전면에 | 짐워크, 플랜핏, Fitbod | 워치 연동이 핵심 판매 포인트 | 우리는 손목 센서로 반복·템포·궤적을 측정 |
| 스토어 이미지의 굵은 한글 헤드라인 | 짐워크, 플랜핏 | 한 화면, 한 메시지 | 화면 제목은 짧게, 큰 숫자 하나로 시선 고정 |

피한 것: 라임/형광 포인트에 꽉 찬 추천 카드(Gym+), 왼쪽 색 줄 카드, 알약형 버튼과 칩, 장식 그라데이션, 모든 행에 반복되는 같은 아이콘, 둥근 카드를 줄줄이 쌓은 목록.

## 글자

- 숫자(경과일, 볼륨, 반복 수, 시계)는 크게, 굵기 Medium, 자간 살짝 좁게. 라벨은 11~13sp 보조색.
- 한 화면에서 큰 숫자는 하나가 주인공. 나머지는 한 단계 작게.
- 안내·질문은 해요체, 버튼·라벨·상태는 명사형 단답을 쓴다. 아래 문구 규칙과 `KoreanToneTest`를 따른다.

## 아이콘

글리프(⌂ ▣ ⚡ ⋮ ⓘ 등)는 환경마다 다르게 그려져서 싸 보인다. 직접 그린 선 아이콘으로 통일한다 (`ui/Icons.kt`): 24 격자, 선 굵기 1.75, 둥근 끝, 꽉 찬 도형 없음.

## 모션 (`Motion`)

패널 300ms easeInOutCirc, 작은 변화 200ms easeInOut, 숫자는 linear 롤링, 스프링·바운스 없음. 단, 기록 갱신 순간(폰 결과·워치 7·8번)만 예외: 오늘 막대가 위로 올라오고 새로 늘어난 점은 한 번 튕기며(스프링 한 번) 생긴다. 모션 줄이기 설정이면 완성된 모양으로 바로 보인다. 새 화면이 열릴 때 숫자와 막대는 한 번 자라난다 (`rememberEntered`).

## 화면별 규칙

1. 홈: 이번 주 요일 막대 → 가장 오래 쉰 루틴(큰 숫자) → 루틴 목록(구분선, 경과일 숫자) → 하단 버튼 하나만 채움.
2. 루틴 상세: 큰 근육 그림 칸 → 운동 행(구분선) → 하단 시작 버튼 하나만 채움.
3. 운동 화면: 위에서 아래로 이미지 → 이름 → 목표/수행 → 볼륨 막대 → 지난번/다음 목표 → 세트 표. 세트 표는 "지난번" 열이 있고 완료 줄은 워시.
4. 휴식: 링은 민트 한 색, 숫자는 롤링.
5. 시트/팝업: 아래 시트 위쪽 16dp, 팝업 10dp, 버튼은 텍스트 또는 채움 하나.
6. 기록/통계: 달력만 카드, 나머지는 구분선 목록과 큰 숫자.

## 문구 규칙 (해요체 + 명사형)

- 버튼, 라벨, 상태는 명사형 단답: 시작, 추가, 삭제, 취소, 운동 완료, 세트 추가 / 휴식 중, 연결 안 됨, 저장 완료.
- 안내, 질문, 알림은 해요체: "운동을 종료할까요?", "순서를 바꿨어요", "연결을 확인해 주세요".
- 반말(~했어, ~해줘, ~할까?, ~돼)과 합쇼체(~합니다, ~하시겠습니까)는 쓰지 않는다. 느낌표와 이모지도 쓰지 않는다.
- 확인 팝업: 제목은 질문, 본문은 결과, 버튼은 구체적인 동사 두 개(계속 운동 / 종료).
- 오류: 무슨 일인지 한 줄, 해결 방법 한 줄.
- 용어 고정: 세트, 회, 무게, 볼륨, 휴식, 루틴, 운동. "삭제"(제거 아님), "종료"(중단 아님), "센서 기록"(원본·capture 아님).
- `core/src/test/.../KoreanToneTest`가 모든 한국어 문구를 훑어 위반이 있으면 테스트를 실패시킨다. 새 문구를 쓸 때 이 테스트가 기준이다.
