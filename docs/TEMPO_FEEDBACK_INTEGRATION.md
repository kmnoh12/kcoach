# 선택적 템포 알림 연결 — 2026-10-15

코덱스1의 TempoFeedbackPolicy와 대상 검사를 8ceff8c로 병합했다.
판정기를 다시 만들지 않고 원래 세션에서 설정/전송/워치 사용 경로를 연결했다.

- 설정에서 운동별 1회 전체/힘쓰는/복귀 구간의 초 범위를 직접 입력한다. 기본 OFF다.
  연속 이탈 횟수와 알림 최소 간격을 정하며 시간 범위가 없는 활성화, 수동/미등록 운동은 거절한다.
- WTS1 스냅샷을 정상 운동 rich command의 추가 21번 필드로 보낸다. 폰 세트/시도 바인딩에 동결하고
  변경은 다음 새 시도부터 적용한다. 현재 시도와 다른 설정은 워치가 거절한다.
- 워치의 해당 스냅샷 저장 SHA 응답이 있어야 명령 완료로 처리한다. 추가 ACK 6번 필드는 템포 SHA,
  5번은 기존 시작 방향 SHA(없으면 빈 값)다. 기존 일반 명령/구형 ACK 읽기는 유지한다.
- 실제 사용한 검증 개인 반복 엔진의 완전 주기에서만 정책을 호출한다. 힘쓰는/복귀 시간은 실제
  전환점과 알려진 위상일 때 전달한다. 불량 신호, 기본 미검증 판정, 수동 세트에는 알림을 만들지 않는다.
- 지속 조건과 알림 간격을 통과하면 워치에 관측 시간/목표보다 빠름·느림을 표시하고 진동한다.
  자세 정확도·피로·RIR 판정이 아니다. 이번 세트의 알림은 워치 버튼으로 즉시 끌 수 있다.
- 설정/음소거/마지막 알림 시각/표시를 워치 runtime과 원본 manifest에 보존한다. 일시정지는 정책의
  연속 조건을 끊는다. 같은 부팅의 복구는 외부 알림 간격을 유지하고, 부팅 시각은 재사용하지 않는다.
- 휴식의 다음 운동 표시와 직전 운동 설정은 구분한다. 재시작 뒤 실제 다음 SET에서 새 운동 설정을
  받으며 휴식 화면에 이전 운동의 템포 표시를 노출하지 않는다.

대상 검사: work/tempo-integration-focused.log와 work/tempo-rest-recovery-focused.log.

판정→알림→음소거/기본 엔진 무알림/휴식 복구를 검사했다. 합성·Robolectric 검사다.
