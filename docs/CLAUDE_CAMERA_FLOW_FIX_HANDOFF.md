# 클로드 → 코덱스2: 카메라 자동 촬영 흐름 결함 수정 (1차 묶음)

2026-10-15, 브랜치 `claude/camera-guide`(main `22f8fbb` 위). push·배포·버전 변경 없음.
수정 파일은 `phone/.../CalibrationCameraActivity.kt` 하나다. 졸라맨 각도와 시작 판정 기준은 바꾸지 않았다.

## 고친 결함

1. 자세를 풀지 않았는데 자동 촬영이 다시 켜짐. 저장 후 결과 화면에서 돌아오면 `onResume → loadWearing()`이
   `poseReady`와 유지 시간을 리셋한다. 기존 `autoStart`는 `!poseReady` 프레임을 "자세 풂"으로 보고 재무장했기 때문에,
   시작 자세 그대로 돌아오면 유지 시간 + 1.5초 뒤 새 촬영이 시작됐다. 이제는 이번 프레임의 기하 판정(`poseCandidate`)이
   실제로 실패했을 때만 재무장하고, 거부 안내(`blocked`)도 그때만 지운다.
2. 카메라 권한 거부 뒤 복구 불가. 설정에서 권한을 허용하고 돌아와도 카메라를 다시 연결하지 않았고,
   "다시 묻지 않음" 상태에서는 "카메라 권한 허용" 버튼을 눌러도 시스템 창이 뜨지 않아 아무 반응이 없었다.
   이제 `onResume`에서 권한이 생겼으면 카메라를 연결하고, 영구 거부면 버튼이 앱 설정 화면을 연다.
3. 워치 확인 중 화면을 벗어나면 백그라운드 촬영. `onStop`의 `stopCapture`는 시작 준비 전이라 아무것도 안 하고,
   늦게 온 워치 노드 응답이 촬영을 준비해 카메라 프레임 없이 워치 START가 나갈 수 있었다.
   이제 노드 응답 시점과 준비 직후에 화면이 STARTED가 아니면 시작하지 않거나 중단 자료로 저장한다.

## 확인했고 문제없던 것

- 정상 저장 직후: `autoStartArmed=false`, `blocked=true`라 같은 자세를 유지해도 재촬영되지 않는다.
- 착용 정보 없음: 상태 문구와 "설정에서 저장" 링크가 있고, 돌아오면 `onResume`에서 다시 읽는다.
- 촬영 중 추적 소실: "팔과 몸통이 가려지지 않게 해 주세요"와 종료 버튼이 유지된다. 저장 실패 시 "저장 다시 시도"가 있다.
