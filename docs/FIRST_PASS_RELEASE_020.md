# 폰·워치 0.2.0 1차 배포 범위

2026-10-15 사용자 지시: 전체 완성까지 기다리지 않고 1차 커밋을 모아 1시간 안에 배포한다.
요청 확인 시각 16:45 KST, 배포 기한 17:45 KST. 기존 전체 목표의 후속 미완료는 별도로 남긴다.

표시 버전은 폰·워치 모두 0.2.0으로 맞춘다. 업데이트 설치를 유지하기 위해 내부 코드는
폰 38→39, 워치 35→36으로 올린다. 기존 서명을 유지하며 앱 삭제/기록 초기화는 요구하지 않는다.
업데이트 판단은 표시 이름이 아닌 versionCode를 사용한다. 태그 p0.2.0-w0.2.0은 조회 시 미존재였다.

## 포함할 1차 묶음

- 현재 main: 기본 프로필·저장된 착용/준비 선택, 중복 없는 시작, 시작 전 세트 강조/휴식 문구,
  늦은 분석의 화면 강제 전환 방지, 정확한 완료 결과 진입과 복구.
- 클로드의 카메라 1~4단계: 졸라맨·상체 촬영·Compose 화면·준비 후 자동 시작.
- 코덱스1 CLI의 첫 워치 UX/완료 결과 열기 커밋과 클로드 CLI의 첫 촬영 흐름 결함 수정:
  반환된 실제 diff를 검토하고, 완료된 묶음만 병합한다.

## 이번 배포와 별도인 항목

실제 Watch8/영상/사람 확인 자료로 횟수 정확도·여러 날 개인 보정 효과를 입증하는 것은 미완료다.
실제 로그인 계정 응답·통합 OTA 설치와 새 카메라/워치 화면의 실기 확인도 코드 검사와 구분한다.
1차 배포를 전체 목표 완료로 표시하지 않는다. 이후 발견된 문제와 미완료 기능은 다음 묶음으로 진행한다.

## 검사와 공개

첫 묶음 통합 후 전체 테스트/lint/OTA는 tools/release.sh로 한 번 실행한다.
실패하면 해당 문제를 고치고 영향받은 검사/산출물을 보완한다. 기한을 맞추려고 실패를 무시해 공개하지 않는다.
기존 인증서 일치, 실제 새 APK의 버전/manifest/JNI/Flogger/Protobuf 보존과 공개 파일 해시를 확인한다.
공개 결과와 남은 범위는 실제 배포 뒤 기록한다.
