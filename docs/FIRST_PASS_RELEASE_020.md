## 최신 사용자 지시 — 폰 화면 검사 제외

사용자가 중단 뒤 배포를 다시 요청했고, 이어서 “폰화면검사하지마라”고 지시했다.
폰 화면 자동검사를 더 실행하지 않으며, 전체 실행의 Compose AppNotIdleException을 통과로 바꾸어 기록하지 않는다.
그래픽 모드 통일 후 대상 묶음은 통과했지만 전체 실행의 시간 초과까지 해결됐다는 근거는 없다.
이번 공개는 사용자 지시로 이 검사 범위를 제외한다. 공통 로직/업데이트/워치 검사와 lint,
새 APK의 버전/서명/필수 선언/공개 해시 확인은 유지한다. 최초 17:45 기한 뒤 중지·재개가 있었으며
실제 공개 시각은 공개 후 기록한다.

확인된 검사: core 275건 중 273 통과/외부 자료 2 제외, updates 14 통과, wear 91 통과.
폰·워치 lint 통과. 폰 전체 실행은 화면 검사 실패/중단이 있어 전체 통과로 표시하지 않는다.
폰의 기존 대상 10건과 개별 대상 통과는 해당 범위의 증거로만 남긴다.

2026-10-15 사용자 지시: 전체 완성까지 기다리지 않고 1차 커밋을 모아 1시간 안에 배포한다.
요청 확인 시각 16:45 KST, 배포 기한 17:45 KST. 기존 전체 목표의 후속 미완료는 별도로 남긴다.

표시 버전은 폰·워치 모두 0.2.0으로 맞춘다. 업데이트 설치를 유지하기 위해 내부 코드는
폰 38→39, 워치 35→36으로 올린다. 기존 서명을 유지하며 앱 삭제/기록 초기화는 요구하지 않는다.
업데이트 판단은 표시 이름이 아닌 versionCode를 사용한다. 태그 p0.2.0-w0.2.0은 조회 시 미존재였다.

## 검사와 공개

첫 묶음 통합 후 전체 테스트/lint/OTA는 tools/release.sh로 한 번 실행한다.
실패하면 해당 문제를 고치고 영향받은 검사/산출물을 보완한다. 기한을 맞추려고 실패를 무시해 공개하지 않는다.
기존 인증서 일치, 실제 새 APK의 버전/manifest/JNI/Flogger/Protobuf 보존과 공개 파일 해시를 확인한다.
공개 결과와 남은 범위는 실제 배포 뒤 기록한다.

통합한 워커 묶음: 클로드 43b5bef/001cad0, 코덱스1 3d6b15c와 그 페이지 전환 기반.
폰의 새 대상 검사 WatchOverviewPublisherTest 2 / CalibrationCameraActivityTest 1 /
CalibrationCameraScreenTest 7, 합계 10건 통과(전체/실기 확인을 뜻하지 않음).
워치 통합 리뷰에서 편집 중 초안 보존이 빠진 것을 확인해 기존 입력 중 저장을 유지했다.
초안 저장은 완료 명령을 보내지 않으며 적용/세트 마치기 분리는 그대로다.

워치 대기 요약 계약은 /kcoach/watch/overview, schemaVersion=1,
generatedAtMs/weekStartDate(월요일)/weekWorkoutCount/recent다.
recent는 null 또는 sessionId/routineName/endedAtMs이며 코덱스1 WatchHomeStore와 맞춘다.
주간 횟수는 폰 홈과 같은 저장 기록/월~일 기준이다. 읽기 실패는 새 0회로 보내지 않고 다음 갱신을 기다린다.
