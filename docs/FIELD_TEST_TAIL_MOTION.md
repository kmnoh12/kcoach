# 실기기 시험표: 세트 뒤 꼬리 동작 오인식

2026-10-16. 목적: 세트 끝에 시계를 보거나 추스르는 동작을 반복으로 잘못 세는지, 그리고 그걸 막는 규칙이 진짜 반복을 놓치게 하는지 재는 것. 지금은 시험 전이라 결과 칸은 비어 있다.

## 방법
- 종목마다 같은 세트를 두 가지로 촬영한다(카메라 + 워치). 촬영 뒤 결과 화면에서 센 횟수와 어긋난 구간 후보를 기록한다.
  - A: 정상 N회 → 세트 종료 버튼(또는 자연스럽게 멈춤).
  - B: 정상 N회 → 시계를 들여다봄(2~3초) → 세트 종료. 5번 반복.
- 안 놓치는지 보려면 C도 한다: 일부러 느린 반복, 크기가 작은 반복, 자세가 무너진 반복을 섞은 세트.
- 종목마다 N은 8~12 사이에서 바꾼다(항상 10으로 하면 목표 횟수에 맞춰진 것인지 구분이 안 된다).
- 목표 횟수를 넘겨 일부러 더 하는 세트(예: 목표 10에 12)도 1번 한다.

## 종목 (엔진별 대표, 나머지는 같은 엔진이면 유사하다고 가정하지 말고 필요 시 추가)
| 종목 | 시계 보기 위험 | 확인할 것 |
|---|---|---|
| 덤벨 컬 | 높음(팔을 들어 올림) | B에서 +1회 오인식 여부 |
| 랫 풀 다운 | 중간(시작 자세가 팔 든 상태) | 끝에 팔을 다시 든 것을 1회로 세는지 |
| 시티드 로우 | 중간 | 끝 동작이 반복으로 세어지는지 |
| 케이블 외회전 | 낮음(회전 동작) | 시계 보기가 회전으로 세어지는지 |
| 스쿼트(카메라) | 해당 없음 | 서 있다가 앉는 준비 동작 오인식 |

## 기록표
| 종목 | 세트 | 실제 횟수 | 워치 횟수 | 어긋난 후보 | 비고 |
|---|---|---|---|---|---|
| | | | | | |

## 판정 기준(시험 전에 정함)
- 꼬리 동작 오인식 0/5 목표. 1회라도 나오면 규칙을 추가한다.
- 규칙 추가 뒤 같은 표를 다시 돌려 진짜 반복의 놓침이 늘지 않았는지 확인한다(C 세트와 목표 초과 세트가 기준).
