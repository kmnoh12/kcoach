# 병행 GPT 이식: 운동 보정 워커 — 2026-10-14

사용자는 촬영/시작 방향/업데이트를 진행하는 코덱스2와 별도로 GPT 이식을 진행하라고 요청했다.
별도 워크트리에서 구현하고 코덱스2의 통합 업데이트 커밋 `6c4cd2b` 위로 재배치해 검사했다.
기존 감지 엔진이나 원본 저장소를 하나 더 만들지 않고, Responses 실행기와 후보/검증/전송 경로를 재사용한다.

## 구현한 경로

`개인 패턴·검증 → 후보의 GPT 보정 도움 → 확인한 원본으로 보정 도움 요청`.
계정·모델·추론 강도는 기존 설정을 사용하고 요청 시 고정한다. 화면 열기/설정 변경만으로 추론하지 않는다.

1. 선택 후보의 고정된 학습 sources만 읽는다. 나중에 촬영한 독립 검증 원본은 모델 입력으로 조회하지 않는다.
   센서 원본 SHA, 확인 revision/digest, 착용/기기/동작 그룹, 카메라 파일 해시와 시계 매핑을 확인한다.
   입력은 안정적인 capture ID 순 첫 6세트, 최대 24개 대표 반복/36,000자 대표 관측으로 제한하고 생략 수를 보존한다.
   각 반복은 실제 관측한 12개 시점의 가속도/각속도와 정렬된 카메라 좌표를 전달한다.
   영상 파일과 전체 원본을 모델에 보내거나 축약 원본으로 덮어쓰지 않는다.
2. 앱이 기존 개인 후보를 같은 학습 원본으로 인과 재생한다. 미래 표본이나 마지막 반복을 닫기 위한 가상 정지 표본을 추가하지 않는다.
   사람이 확인한 전체 횟수와 완전히 확인한 경계가 있을 때만 해당 오차를 계산한다.
3. 모델에 `measurement_calibration`을 한 번 요청한다. request/input 해시, 근거/엔진/후보 ID와 제한된 매개변수만 허용한다.
   maximum_distance(normalized_dtw), minimum_duration_ms와 maximum_duration_ms(ms)의 registry 범위를 검사한다.
   코드, 템플릿, 축, 원본, 라벨 변경은 지원하지 않는다. 사람 확인 횟수가 없으면 제안 후보를 수락하지 않는다.
4. 제안을 원본으로 재생하고 입력 변경을 다시 확인한다. 기존 `PatternCandidateStore`에 같은 sources의 새 버전으로 저장한다.
   모델/강도/프롬프트 해시/입력 해시/제안/재생/후보 해시/단계 시간을 별도 메타데이터로 보관한다.
   후보·원본을 복제하는 다른 엔진 저장소는 없다. 같은 입력·모델·강도·프롬프트의 완료 결과는 재사용한다.
5. 새 후보는 `독립 검증 대기`다. 기존 목록의 새 자료 검증, 실제 워치 검증, 고정 자료 회귀 검사와
   `PatternAdoptionController`의 다음 세트 요청·실제 사용 ACK·롤백 경로를 거쳐야 한다.
   GPT의 확신이나 학습 자료 재생 결과만으로 워치 설정을 활성화하지 않는다.

45초 전경 제한은 입력/모델/재생 단계의 취소 체크와 실제 HTTP 연결 취소에 연결했다.
실패/미완료/취소/늦은 응답/프로세스 중단 시 원본과 현재 설정을 유지하고 자동 재요청하지 않는다.
입력 조립·재생·후보 저장은 작업 스레드에서 수행한다. 모델이 실행 중일 때만 모델 대기 상태를 표시한다.

새 확인 자료로 기존 `buildForCapture`가 누적 학습 후보를 만들면 그 후보에도 같은 도움을 요청할 수 있다.
원본을 다시 맞히는 학습 비교와 새로운 자료의 독립 검증은 계속 구분한다.

## 검증과 남은 것

최신 통합 업데이트 코드 위에서 코어 222개(기존 외부 자료 검사 2개 생략), 폰 267개 검사 통과.
Debug APK 빌드와 린트 오류 검사도 통과했다. 수치는 `reviews/2026-10-14-gpt-calibration-worker.json`에 기록했다.
검사는 합성 원본·가짜 모델 응답과 저장 형식 테스트다. 실제 영상 인식·Watch8 정확도·실제 계정 추론을 증명하지 않는다.
실제 모델 응답 30초 목표의 p50/p95, 실제 폰 취소/재생성, 실제 워치 사용 ACK/개선/롤백은 남아 있다.

공통 호출기·상담/수동 리뷰에 이어 이번 보정 워커 소프트웨어까지 연결됐다. 자동 적용 설정,
개인 엔진 목록의 이력 UI 전체 통합과 실제 계정/기기 검증은 계속 남은 범위다.
현재 보정 호환 키는 기존 손·손등/안쪽 착용·기기·센서 좌표 기준이다. 원래 작업의 본체 위쪽 방향/수행 변형
계약이 추가되면 그 조건과 보정 자료의 호환성도 함께 검증해야 한다. 기존 자료에 새 착용 조건을 추정해 붙이지 않는다.
촬영 오류/시작 방향/통합 업데이트 파일은 이번에 변경하지 않았다. 버전/공개 APK도 바꾸지 않았다.

이 경로를 다시 작성하지 말고 남은 검증·UI·실제 계정 연결을 이어간다.
