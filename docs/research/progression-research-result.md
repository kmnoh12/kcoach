# 결론 요약

**이중 점진을 기본으로 삼는 방향은 타당해. 다만 바벨 5·10kg 고정 증량과 ‘모든 운동을 e1RM 하나로 진행’은 수정하는 게 좋아.** 실제 달성 기록을 진행의 기준으로 두고, 추정 1RM(e1RM)은 증량 폭과 다음 횟수를 점검하는 보조 계산으로 쓰는 쪽을 권고해.

아래에서 **연구 결과**, **코칭 경험칙**, **워치짐 정책 초안**을 구분했어. 코드와 파일은 수정하지 않았어.

| 설계 항목 | 판정 | 권고 |
|---|---|---|
| ① 횟수 먼저, 무게 나중 | **근거 있음** | 횟수 증가와 중량 증가 모두 유효한 진행 방법. 다만 정확한 이중 점진 알고리즘의 우월성까지 입증된 것은 아님 |
| ① 세트별 독립 진행 | **경험칙** | 서로 다른 목표를 처리하기에 적합. 세트 역할·순서·장비를 고정해 비교해야 함 |
| ① 웜업 제외 | **근거 있음 / 구현 원칙** | 작업 세트의 적응을 판단할 때 웜업을 섞으면 안 됨. 가벼운 작업 세트를 웜업으로 추측해서도 안 됨 |
| ② 실패해도 중량 유지, 감량은 제안만 | **경험칙** | 사용자 통제 정책으로 타당. 반복 실패 시 자동 증가는 중단해야 함. ‘계속 유지가 생리적으로 최적’이라는 근거는 없음 |
| ③ 바벨 5·10kg만 증량 | **수정 권고** | 가벼운 컬·오버헤드프레스 등에 너무 큼. 실제 가능한 최소 단위와 상대 증가율을 함께 봐야 함 |

| ③ 핀 간격을 기록의 이웃 차이 최빈값으로 추정 | **직접 근거 못 찾음** | 구현 가능한 추정법이지만, 건너뛴 핀 간격을 최소 간격으로 오인할 수 있음 |
| ④ e1RM을 모든 운동의 공통 진행 지표로 사용 | **수정 권고** | 같은 운동·장비 안의 보조 지표로 제한. 운동 간 공통 능력 점수로 쓰지 않는 게 좋음 |
| ④ e1RM을 비슷하게 유지하도록 증량 후 횟수 계산 | **수학적으로 근거 있음 / 실전 검증 부족** | 시작 목표를 산출하는 휴리스틱으로 가능. 실제 성공 횟수를 보장하지 않음 |
| ④ 계산 횟수가 너무 낮으면 작은 증량 선택 | **경험칙이지만 합리적** | 고정 4~5회보다 **해당 세트의 하한**을 기준으로 판단 |
| ⑤ 후반 속도 저하는 참고만 | **근거 있음** | 손목 속도·파형을 바벨 속도나 남은 반복 수로 바로 해석하면 안 됨 |

# 1. ACSM 2009 원문과 2026 개정판

## 2009: 기억한 기준이 맞음

*Progression Models in Resistance Training for Healthy Adults*, **Medicine & Science in Sports & Exercise, 2009;41(3):687–708**, 본문 **p.690, Loading의 Evidence category B**에서 확인했어.

핵심 원문 표현은 다음과 같아.

> “2–10%”  
> “one to two repetitions over the desired number”  
> “on two consecutive training sessions”

즉, **정해진 RM 부하에서 목표보다 1~2회를 더 수행하는 것을 같은 운동의 두 번 연속 훈련에서 달성하면 2~10% 증량**한다는 권고야. 작은 근육량을 사용하는 운동은 낮은 증가율, 큰 근육량을 사용하는 운동은 높은 증가율을 제시해. **Table 2, p.700에도 같은 기준이 반복**돼. [ACSM 2009 원문 PDF](https://www.researchgate.net/profile/Brent-Alvar/publication/235653976_Progression_models_in_resistance_training_for_healthy_adults_ACSM_position_stand/links/00b4951cdbb16cd02b000000/Progression-models-in-resistance-training-for-healthy-adults-ACSM-position-stand.pdf)

해석할 때는 세 가지를 구분해야 해.

- 초록에는 **두 번 연속** 조건이 생략되어 있지만 본문에는 있어.
- 이 문장은 **모든 세트가 상한 도달**, **세트마다 독립 증량**, **상한에서 정확히 멈춰도 증량**을 명시하지 않아.
- 근거 등급 B인 권고이지, 가능한 모든 진행 알고리즘과 비교해서 이 숫자 조합이 최적임을 입증한 결과는 아니야.

해당 문장의 인용문헌 68번은 Feigenbaum & Pollock의 *Prescription of resistance training for health and disease*, **MSSE, 1999**야. 권고의 존재와 정확한 문구는 확인했지만, 이 규칙 자체의 최적성을 검증한 단일 비교시험으로 해석하면 안 돼.

## 2026: 실제 개정판이 있음

*Resistance Training Prescription for Muscle Function, Hypertrophy, and Physical Performance in Healthy Adults: An Overview of Reviews*, **MSSE, 2026;58(4):851–872**, DOI **10.1249/MSS.0000000000003897**이 2009 입장문을 갱신했어. 137개 체계적 문헌고찰을 종합한 문서야. [ACSM 공식 발표](https://acsm.org/science-spotlight-acsm-releases-new-position-stand-on-resistance-training/), [2026 논문 본문 PDF](https://www.fisiologiadelejercicio.com/wp-content/uploads/2026/03/Resistance-Training-Prescription-for-Muscl.pdf)

| 관점 | 2009 | 2026 |
|---|---|---|
| 진행 규칙 | 1~2회 초과·두 번 연속·2~10%라는 구체적 권고 | 이에 대응하는 새로운 단일 수치 규칙은 확인되지 않음 |
| 강조점 | 훈련 경력과 목표별 구체적 처방 | 개인화, 지속 가능한 참여, 목표에 맞는 부하·볼륨 |
| 점진적 과부하 | 지속적 발전의 핵심 원칙 | 장기 발전에는 자극 증가가 중요하지만, 초기 효과를 얻기 위해 매번 진행할 필요는 없다고 설명 |
| 실패 훈련·복잡한 주기화 | 다양한 구체적 모델 제시 | 일반 건강 성인에서 일관된 추가 이득을 보이지 않는 요소가 많다고 정리 |

**2009 규칙이 틀려졌다는 뜻은 아니야.** 다만 이를 “2026 ACSM이 재검증한 필수 알고리즘”이라고 표현할 근거는 없어.

# 2. 이중 점진과 2-for-2의 근거 수준

| 규칙 | 확인한 출처 | 근거 해석 |
|---|---|---|
| 횟수 또는 중량을 늘려 진행 | Plotkin 등, **PeerJ, 2022** | 경력자 43명·8주 하체 훈련에서 두 방식 모두 적응을 유도. 정확한 혼합 알고리즘의 비교는 아님 |
| 횟수 또는 중량 증가 | Chaves 등, **International Journal of Sports Medicine, 2024** | 초보자 39명·10주 레그 익스텐션에서 두 방식 모두 근력·근비대 향상 |
| 이중 점진 | Mike Matthews의 본인 프로그램 설명 | 범위 상단 달성 후 증량하는 **코칭 방법**. 필요한 상한 세트 수 등은 경험칙 |
| 2-for-2 | NSCA 교재 계열 및 USU/HPRC 교육자료 | 마지막 세트에서 목표보다 2회 더 수행하는 것을 반복 확인한 뒤 증량하는 **실무 지침** |
| 모든 운동을 세트별 이중 점진으로 자동 진행 | 이번 조사에서 직접 비교 근거 못 찾음 | 위 원칙을 앱에 맞게 구성한 제품 정책 |

논문 출처: [Plotkin 등, 2022](https://pubmed.ncbi.nlm.nih.gov/36199287/), [Chaves 등, 2024](https://pubmed.ncbi.nlm.nih.gov/38286426/). 코치 본인 설명: [Matthews의 Double Progression](https://legionathletics.com/double-progression/).

2-for-2는 **‘상한에 두 번 도달’과 완전히 같은 규칙이 아니야.** 통상적인 설명에는 **마지막 세트·목표보다 2회 초과**가 들어가. USU/HPRC는 NSCA 교재를 인용하면서 이를 소개하지만 “2주 연속”이라고 표현해. ACSM 원문은 “두 번 연속 훈련”이므로 앱에서는 **달력 주가 아니라 동일 운동의 유효 수행 회차**로 세는 편이 명확해. [USU/HPRC 공식 교육자료, 2021](https://www.hprc-online.org/physical-fitness/training-performance/guidelines-progress-your-physical-training-over-time)

워치짐은 **상한 도달 후 두 회차 확인하는 이중 점진**으로 설명하면 돼. 이를 그대로 ACSM 원문 또는 정통 2-for-2라고 부르지는 않는 게 정확해.

# 3. 1RM 추정 공식: 사용할 범위와 오차

## 먼저, 실제 반복 수와 최대 가능 반복 수는 다름

고전적인 공식은 대체로 **실패까지 수행한 반복 수**, 또는 그에 가까운 RM 수행을 전제로 해.

`30kg×10회`에서 사용자가 목표만 채우고 멈췄다면, 실제로 13회가 가능했는지는 센서 횟수만으로 알 수 없어. **횟수를 정확히 세는 것과 근력 한계를 아는 것은 별개**야.

따라서 RIR을 받지 않는 워치짐에서는 계산값을 **‘해당 기록에서 계산한 e1RM’**으로 다루는 게 맞고, 실제 최대근력으로 단정하면 안 돼. 반복 수와 %1RM 관계의 운동별·개인별 변이는 Nuzzo 등의 대규모 메타회귀에서도 확인돼. [Nuzzo 등, *Sports Medicine*, 2024; 온라인 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10933212/)

## 공식별 권고

\(w\): 기록한 중량, \(r\): 반복 수.

| 공식 | 계산식 | 워치짐에서의 권고 |
|---|---|---|
| Epley | \(w(1+r/30)\) | 기본 보조 계산으로 **2~10회**. 1회는 별도 처리해 \(w\) |
| Brzycki | \(36w/(37-r)\) | **2~10회**에서 보조 비교 가능. 고반복 외삽 금지 |
| Lombardi | \(wr^{0.1}\) | 일부 표본에서 좋은 결과가 있지만 보편적 우위 없음. 기본 공식으로 바꿀 근거 부족 |
| Mayhew | \(100w/(52.2+41.9e^{-0.055r})\) | 벤치 중심 검증 맥락에서 참고. 모든 운동으로 확대하지 않음. 1~2회 입력에는 부적합 |

공식과 검증 맥락은 [Reynolds 등, *JSCR*, 2006 원문](https://www.unm.edu/~rrobergs/478RMStrengthPrediction.pdf), [LeSuer 등, *JSCR*, 1997 원문](https://paulogentil.com/pdf/The%20Accuracy%20of%20Prediction%20Equations%20for%20Estimating%201-RM%20Performance%20in%20the%20Bench%20Press%2C%20Squat%2C%20and%20Deadlift.pdf)에서 확인했어.

이 표의 **10회 제한은 앱에서 사용할 보수적 경계**야. “Epley는 모든 운동에서 10회까지 오차 ±5%”처럼 보장된다는 뜻은 아니야. 반복 수에 따라 공식을 바꾸면 공식 차이가 진행 추세에 섞이므로, 한 운동에서는 같은 공식을 유지하는 편을 권고해.

## 반복 구간 × 운동 종류

**요청한 모든 조합에 공통으로 적용할 오차율 표는 문헌에서 찾지 못했어.** 확인되지 않은 칸에 임의로 ±5%, ±10%를 붙이는 대신, 근거 범위와 사용 제한을 정리했어.

| 반복 구간 | 바벨 복합 | 덤벨 | 머신 고립 | 권고 |
|---|---|---|---|---|
| 1~5회 | 상대적으로 추정에 유리하지만 운동별 편향 존재. 1회 수행이 실제 최대였는지는 별도 문제 | 범용 공식의 직접 검증이 부족 | 운동별 검증 필요 | 2~5회 기록의 보조 계산 허용 |
| 6~10회 | 검증 연구가 비교적 많음. 벤치 결과를 데드리프트 등에 그대로 옮길 수 없음 | 벤치 연구의 오차율을 차용할 수 없음 | 레그 익스텐션에서도 공식·훈련 전후에 따라 오차 변화 | 보조 계산 허용, 실제 달성 기록 우선 |
| 11~15회 | 개인별 반복 내구력 영향과 공식 간 차이가 커짐 | 구간별 검증 부족 | 구간별 일반화 근거 부족 | 표시·참고 수준. 자동 증량의 단독 기준으로 사용하지 않음 |
| 15회 초과 | 고전 공식의 일반화가 약함. 20RM은 5RM보다 예측 오차 증가 | 근거 부족 | 근거 부족 | 반복 성과로 진행. e1RM 기반 자동 환산 제외 |

### 수치로 확인되는 오차 사례

**Reynolds 등, JSCR, 2006**에서 연구자가 만든 운동별 회귀식의 개발 표본 예측 표준오차는 다음과 같았어.

| 입력 | 바벨 벤치프레스 | Cybex 플레이트 로드 레그프레스 |
|---|---:|---:|
| 5RM | 2.98kg | 16.16kg |
| 10RM | 5.38kg | 26.13kg |
| 20RM | 7.36kg | 29.41kg |

이는 **Epley의 오차 표가 아니며**, 10RM 벤치식에는 제지방량도 포함돼. 독립 검증에서도 5RM이 가장 유리했어. 저자들은 레그프레스 공식을 다른 기계로 일반화하지 말라고 명시해. 표준오차 역시 개인의 최대 오차나 95% 보장구간이 아니야. [Reynolds 등, 2006](https://www.unm.edu/~rrobergs/478RMStrengthPrediction.pdf)

**Pioske 등, International Journal of Sports Science, 2025**는 남성 28명의 레그 익스텐션을 검증했어. 첫 수행은 3~11회, 마지막 수행은 4~11회였고, 비교한 다섯 식의 총오차(TE)는 훈련 전 **5.09~7.73kg**, 후 **5.82~13.19kg**였어. 실제 1RM 증가량도 모두 평균적으로 과대평가했어. **수준을 어느 정도 추정하는 것과 증가량을 정확히 추적하는 것도 다르다**는 사례야. 이 연구가 Epley·Brzycki·Mayhew 모두를 비교한 것은 아니야. [Pioske 등, 2025 본문](https://www.researchgate.net/publication/394094518_Validity_of_Repetitions_to_Failure_to_Estimate_and_Track_Changes_in_Leg_Extension_One-Repetition_Maximum)

또한 **Ribeiro 등, IJSC, 2024**에서는 남성의 벤치·스쿼트에 Lombardi가 상대적으로 적합했지만, 남성 암컬에는 비교한 모든 공식이 실제 값과 유의한 차이를 보였어. 공식 순위도 운동과 표본에 따라 바뀐다는 뜻이야. [Ribeiro 등, 2024](https://journal.iusca.org/index.php/Journal/article/download/327/417/)

## 센서가 ±1회 틀렸을 때

아래는 **같은 중량에서 반복 입력만 ±1 바꾼 순수 계산 오차**야. 공식 자체의 예측 오차나 센서의 실제 검증 결과는 포함하지 않았어.

| 실제 반복 수 | Epley: −1 / +1회 | Brzycki | Lombardi | Mayhew |
|---|---:|---:|---:|---:|
| 5회 | −2.86% / +2.86% | −3.03% / +3.23% | −2.21% / +1.84% | −2.10% / +2.07% |
| 10회 | −2.50% / +2.50% | −3.57% / +3.85% | −1.05% / +0.96% | −1.76% / +1.72% |
| 15회 | −2.22% / +2.22% | −4.35% / +4.76% | −0.69% / +0.65% | −1.45% / +1.41% |
| 20회 | −2.00% / +2.00% | −5.56% / +6.25% | −0.51% / +0.49% | −1.18% / +1.14% |

15·20회 행은 민감도를 보여주기 위한 계산이며 사용 권고가 아니야. **±1회에 둔감한 공식이 실제 1RM에도 더 정확하다는 뜻은 없어.**

예를 들어 Epley에서 `30×10`은 40kg, `30×9`는 39kg, `30×11`은 41kg이야. ±1회만으로 작은 증량에 해당하는 차이가 생기고, e1RM 변화보다도 **상한 성공 판정을 뒤집는 영향**이 중요해.

# 4. 우리 설계의 증량·횟수 복귀 검증

## (a) 바벨 5·10kg 고정 증량

| 현재 중량 | +5kg | +10kg | 해석 |
|---|---:|---:|---|
| 20kg | +25.0% | +50.0% | 가벼운 바벨 운동의 일괄 증량으로 부적합 |
| 30kg | +16.7% | +33.3% | 컬·프레스에서 큰 도약 |
| 40kg | +12.5% | +25.0% | +5kg도 ACSM의 일반 권고 범위 초과 |
| 80kg | +6.25% | +12.5% | +5kg은 검토 가능, +10kg은 큼 |
| 100kg | +5.0% | +10.0% | 상대 증가율상 검토 가능한 구간 |
| 200kg | +2.5% | +5.0% | 같은 절대 증량의 부담이 훨씬 작음 |

**바벨이라는 장비 종류만으로 증량량을 결정하면 안 돼.** 특히 작은 근육량을 사용하는 운동에는 더 작은 비율을 권고한 ACSM 2009와도 맞지 않아.

실제로 5kg 단위만 가능한 환경이라면 그 제약은 반영해야 해. 하지만 작은 단위가 없는 상태에서 “한 단계 작게”를 실행할 수는 없어. 이때는 **증량을 보류하거나, 반복 범위를 넓히거나, 더 작은 원판 사용을 제안**해야 해.

덤벨도 마찬가지야. 한 손 10kg에 +1kg은 10%, +2kg은 20%다. 기록이 한 손 중량이면 증량도 한 손 단위로 계산해야 해.

## (b) 상한 후 하한 복귀가 e1RM을 유지하는가?

**항상 그렇지는 않아.**

Epley를 사용할 때 이전 기록 \(w,r\)와 같은 e1RM을 만드는 새 중량 \(w'\)의 반복 수는:

\[
r_{\mathrm{eq}}=30\left(\frac{w(1+r/30)}{w'}-1\right)
\]

| 전환 | 이전 e1RM | 같은 e1RM에 해당하는 새 반복 수 | 예시 목표의 의미 |
|---|---:|---:|---|
| 80×8 → 85kg | 101.33kg | 5.76회 | 85×5는 e1RM 약 **−2.1%** |
| 30×10 → 35kg | 40.00kg | 4.29회 | 35×5는 약 **+2.1%** |
| 20×10 → 25kg | 26.67kg | 2.00회 | +5kg 때문에 반복 구간이 크게 바뀜 |
| 40×10 → 45kg | 53.33kg | 5.56회 | 6~10회 세트라면 하한 유지도 빠듯함 |

이 수치는 **공식에 따른 직접 계산**이야. 실제 가능한 반복 수 예측을 검증한 결과는 아니야.

또한 `80×8→85×5`는 세트의 중량×반복이 640에서 425로 약 33.6% 감소해. 이것만으로 자극이 부족하다고 단정할 수는 없지만, **e1RM 유지가 훈련량·노력도·근비대 자극의 동일함을 뜻하지는 않는다**는 점은 분명해.

## (c) 실패율을 낮추려면

다음 순서를 권고해. **구체적인 반올림·확인 횟수는 앱 정책 초안**이야.

1. 해당 세트가 고정된 상한을 반복 달성했는지 확인한다.
2. 장비에서 실제 선택 가능한 **가장 작은 증량**을 우선 검토한다.
3. 2~10회 기록에서는 위 식으로 다음 반복 수를 계산하고 **내림**한다.
4. 계산 결과가 세트 하한보다 낮으면 작은 증량을 다시 찾는다.
5. 가능한 증량이 없으면 현재 중량을 유지한다. 계산값을 하한으로 강제로 올리지 않는다.
6. 새 중량 첫 회차의 실제 수행으로 다음 목표를 보정한다.

예를 들어 6~10회 세트의 `30×10→35kg`은 계산 결과가 4회이므로 보류가 맞아. “최소 5회니까 5회 입력”은 계산상 요구 강도를 올리는 행동이야.

정확한 실패율 감소 폭을 입증한 연구는 찾지 못했어. RIR 없이 운영한다면 **작은 증량·반복 확인·보수적 정수 목표**가 현실적인 방법이야.

# 5. 세트별 이중 점진: 피라미드·역피라미드·백오프

Martin Berkhan의 RPT 설명에는 첫 세트 성과에 연결하는 방식과 세트를 독립 진행하는 방식이 구분돼. **둘 다 실무 모델이며, 모든 구조에 독립 진행이 우월하다는 근거는 아니야.** [Berkhan, Reverse Pyramid Training Guide, 2018](https://leangains.com/reverse-pyramid-training-guide/)

| 구조 | 적용 초안 | 흔한 함정 |
|---|---|---|
| 동일 중량 작업 세트 | 각 세트의 상한·성공 이력 관리 | 첫 세트 증량으로 뒤 세트가 피로해져도 서로 무관하다고 가정 |
| 상승 피라미드 | 가벼운 작업 세트와 무거운 작업 세트에 서로 다른 범위 유지 | 가벼운 세트를 웜업으로 추정하거나, 마지막 세트의 상한을 모두에게 적용 |
| 역피라미드 | 첫 무거운 세트와 후속 세트를 같은 역할끼리 비교 | 후속 세트까지 첫 세트와 같은 횟수·무게로 덮어쓰기 |
| 백오프 | 독립 진행인지, 탑 세트 중량의 일정 비율인지 먼저 구분 | 비율로 정한 중량에 독립 증량도 적용해 두 번 올림 |

`60×10, 60×10, 80×7`이 모두 작업 세트라면 각각의 범위를 보존해야 해. 1·2세트가 상한을 채웠다고 3세트까지 증량할 이유는 없어.

필요한 비교 단위는 **운동명만이 아니라 루틴 내 운동 위치 + 장비 + 세트 역할/안정적인 ID**야. 세트를 추가하거나 순서를 바꾼 뒤 단순히 “지난번 3번 세트”와 연결하면 다른 조건을 비교하게 돼.

세트 구성·순서·주요 선행 부하가 바뀐 회차는 비교 가능성을 다시 판단하고, 새로 생긴 세트에는 이전 성공 횟수를 물려주지 않는 편을 권고해. 이는 연구로 확정된 숫자 규칙이 아니라 기록 비교의 일관성을 위한 설계야.

# 6. 속도 슬라이더: 3단계 권고

**속도는 생리학적 성장 속도나 반복 수행 속도가 아니라 ‘목표를 올리는 보수성’으로 정의하는 게 좋아.** 다음 매핑을 직접 검증한 연구는 없어.

범위 상한 \(U\), 현재 목표 \(T\)는 분리해서 저장해야 해. 목표가 8→9→10으로 늘어날 때 **상한까지 같이 올라가면 증량 조건에 영원히 도달하지 못해.**

| 속도 | 반복 목표 +1 조건 | 증량용 상한 조건 | 필요한 연속 상한 성공 | 증량 크기 |
|---|---|---|---:|---|
| 느리게 | 같은 목표를 2회 달성 | \(r \ge U\) | 3회 | 가능한 최소 1단계 |
| 보통 | 현재 목표를 1회 달성 | \(r \ge U\) | 2회 | 가능한 최소 1단계 |
| 빠르게 | 현재 목표를 1회 달성 | \(r \ge U\) | 1회 | 가능한 최소 1단계 |

**빠르게에서도 핀 두 칸·바벨 +10kg으로 확대하는 건 기본값으로 권하지 않아.** 대기 횟수만 바꿔도 진행 속도는 충분히 달라져.

공통 증량 검토 기준의 초안은 다음과 같아.

- 작은 근육 운동·상체 운동: 우선 **현재 중량의 5% 이내**.
- 큰 하체 복합 운동: **10% 이내**까지 검토.
- 비율을 통과해도 증량 후 목표가 세트 하한 미만이면 보류.
- 최소 장비 간격부터 기준을 넘으면 숫자를 가상으로 쪼개지 않고 유지·간격 확인.

5%·10% 구분은 ACSM의 2~10% 범위를 앱에 보수적으로 적용한 **정책값**이야. 2% 미만의 작은 증량을 금지할 이유는 없어.

# 7. 맨몸·가중 풀업·수동 입력 운동

| 유형 | 진행 규칙 초안 | 주의점 |
|---|---|---|
| 맨몸 풀업·딥스 | 세트별 횟수 증가. 상한 반복 달성 후 가중 또는 변형 변경 제안 | 사용자가 중량 장비를 쓰겠다고 정하기 전에는 가중을 자동 생성하지 않음 |
| 가중 풀업 | 추가 중량을 입력하되 계산에는 체중+추가 중량 사용 | 추가 중량만으로 e1RM을 계산하면 맨몸 0kg 문제 발생 |
| 어시스트 풀업 | 상한 달성 후 보조 중량을 한 칸 **감소** | 보조 무게 감소가 난도 증가. 일반 머신과 방향이 반대 |
| 푸시업 | 같은 변형에서 반복 증가. 상한 이후 난도 변경 제안 | 체중 전체를 그대로 외부 부하처럼 환산하지 않음 |
| 레그프레스 등 수동 기록 | 수동 확정 횟수에 동일 진행 규칙 적용 | 손목 측정이 안 된다고 진행 자체를 막을 필요는 없음 |
| 시간 기반 운동 | 시간 기록으로 별도 진행 | 횟수·e1RM 엔진에 억지로 넣지 않음 |

가중 풀업에서 체중 70kg, 추가 10kg이면 총부하 근사는 80kg이야. 추가 5kg은 **추가 중량 기준 50%**지만 **총부하 기준 6.25%**야. 체중 변화를 반영하되, 총부하 공식 역시 종목별 검증이 필요한 근사로 다뤄야 해. 풀업의 최대 부하를 체중을 포함해 다루는 연구 맥락은 확인돼. [Johnson 등, *JSCR*, 2009](https://www.researchgate.net/profile/Doug-Johnson-2/publication/24350694_Relationship_of_Lat-Pull_Repetitions_and_Pull-Ups_to_Maximal_Lat-Pull_and_Pull-Up_Strength_in_Men_and_Women/links/5a12f6abaca27217b59e933f/Relationship-of-Lat-Pull-Repetitions-and-Pull-Ups-to-Maximal-Lat-Pull-and-Pull-Up-Strength-in-Men-and-Women.pdf)

입력 우선순위는 **사용자 수정값 → 채택된 센서값**, 측정 불가능한 운동은 수동값으로 두면 돼. 손목으로 레그프레스 반복을 확인할 수 없는데 0회로 넣어 실패 처리해서는 안 돼.

파형의 후반 감속은 기록 옆 참고 설명으로 유지하는 방향을 지지해. 스마트워치 기반 연구에서도 속도 추정으로 1RM을 예측하는 정확성에 추가 개선이 필요했어. 이 결과가 워치짐 센서 성능을 검증해 주는 것은 아니야. [스마트워치 운동 분석 검증 연구, *Sensors*, 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8471343/)

# 8. 정체기와 디로드

**‘몇 번 정체하면 반드시 디로드’라는 확정된 기준은 찾지 못했어.** 디로드 설계에는 전문가 합의와 선수들의 실제 관행이 있지만, 효능과 최적 시점을 입증하는 연구는 제한적이야.

- **Bell 등, Sports Medicine–Open, 2023:** 전문가 Delphi 합의. 디로드를 피로 완화와 이후 훈련 준비를 위한 훈련 스트레스 감소로 정의. 비교시험은 아님. [논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC10511399/)
- **2024 선수 설문:** 평균 약 6일, 약 5.6주 간격으로 시행했다고 보고. **관행의 기술이지 최적 주기 증명은 아님.** [논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC10948666/)
- **Coleman 등, PeerJ, 2024:** 중간에 1주 완전히 쉰 집단에서 근비대 이득은 더 크지 않았고, 하체 근력 향상은 연속 훈련 집단에 유리했어. 일반적인 ‘가볍게 운동하는 디로드’와 구분해야 해. [논문](https://pubmed.ncbi.nlm.nih.gov/38274324/)
- **Pancar 등, Scientific Reports, 2026:** 초보 남성 19명의 8주 연구에서 일부 주의 세트 수·빈도를 줄여도 근두께와 10RM 향상에 뚜렷한 집단 차이를 검출하지 못했어. 경력자나 최대근력에 그대로 일반화할 수 없어. [논문](https://www.nature.com/articles/s41598-026-40612-5)

앱에서는 아래처럼 표현하는 게 좋아. **회차와 감량 수치는 정책 초안**이야.

| 상태 | 제안 |
|---|---|
| 목표 미달 1~2회 | 무게·목표 유지. 추가 증량 중단 |
| 같은 조건에서 3회 연속 진전 없음 | “최근 3회 기록이 비슷해. 휴식 시간과 운동 간격을 확인해 봐.” |
| 5~6회 정체 또는 여러 운동에서 수행 하락 | 회복 주간, 더 작은 증량 간격, 루틴 조정 제안 |
| 사용자가 회복 주간 선택 | 예: 1주간 작업 세트 약 30~50% 감소. 필요하면 중량 감소도 사용자가 선택 |
| 회복 주간 종료 | 기존 진행 기준을 보존하되 실제 복귀 수행 확인 후 재개 |

화면에는 **“회복 주간 — 이번 주 작업 세트 4→2”**처럼 바뀌는 내용을 보여주고, 적용 전에는 기존 계획을 유지하면 돼. 회복 주간 기록은 정체·실패·증량 성공 누적에서 제외해야 해.

# 엔진에 넣을 수 있는 규칙 표 초안

아래는 연구 원칙을 바탕으로 만든 **워치짐 정책안**이야. 세부 숫자 전체가 임상·훈련시험으로 검증된 알고리즘은 아니야.

기호: \(L,U\)=고정 반복 범위, \(T\)=이번 목표, \(r\)=실제 반복, \(w\)=현재 중량, \(d\)=장비의 실제 증량분.

| 조건 | 행동 | 수치·판정 |
|---|---|---|
| 웜업 세트 | 진행 계산 제외 | 명시된 세트 유형 사용 |
| 미완료·횟수 미입력 | 성공/실패 누적 제외 | 0회로 간주하지 않음 |
| 사용자 횟수 수정 | 수정값으로 판단 갱신 | 센서값보다 우선 |
| \(r<T\) | 중량·목표 유지 | 해당 성공 연속 횟수 초기화, 자동 감량 없음 |
| \(T<U\), 목표 달성 | 속도별 확인 후 목표 증가 | \(T'=T+1\), 최대 \(U\) |
| \(T=U\), 상한 달성 | 증량 성공 누적 | 느림 3 / 보통 2 / 빠름 1회 |
| 증량 조건 충족 | 최소 실제 증량부터 검토 | 운동별 5% 또는 10% 이내를 우선 기준 |
| 2~10회 기록의 증량 | 다음 반복 목표 계산 | \(\left\lfloor30\{w(1+r/30)/(w+d)-1\}\right\rfloor\) |
| 위 계산이 \(L\) 이상 | 새 중량과 계산 목표 적용 | \(U\)를 넘으면 \(U\)로 제한 |
| 위 계산이 \(L\) 미만 | 작은 증량 재검토 | 없으면 유지. \(L\)로 강제 올림 금지 |
| 11회 이상 기록 | e1RM 환산을 단독 결정에 사용하지 않음 | 작은 증량·반복 확인·실제 수행 중심 |
| 고반복의 초기 대체 규칙 | 작은 증량만 허용하고 목표 복귀 | 정책 초안: 2회 상한 성공, 증가율 ≤5%, 목표 \(\max(L,U-2)\). 큰 간격은 보류 |
| 최소 간격이 너무 큼 | 유지하고 해결책 제안 | 작은 원판·핀 간격 확인·범위 확장 중 선택 |
| 핀 간격 미확정 | 같은 장비의 기록에서 후보 추정 | 다른 머신·케이블 비율·단위 혼합 금지 |
| 핀 간격 자료 부족·모호 | 한 번 질문 | 예: “이 머신은 한 칸이 5kg이야?” |
| 세트 추가·순서·역할 변경 | 비교 이력 재설정 또는 재매칭 | 배열 번호만으로 성공 이력 승계 금지 |
| 3회 정체 | 점검 안내 | 계획 자동 변경 없음 |
| 5~6회 정체·광범위 하락 | 회복/루틴 조정 제안 | 사용자 선택 후만 적용 |
| 새 루틴 열기 | 확정 기록으로 계산한 다음 목표 선입력 | 추천 버튼 없이 반영 |
| 같은 루틴 반복 열기 | 같은 결과 유지 | 화면을 열 때마다 추가 증량하지 않음 |
| 사용자가 목표 직접 변경 | 해당 목표 존중 | 같은 회차의 자동 계산으로 다시 덮어쓰지 않음 |

핀 간격 추정은 **‘기록에서 관측한 간격’과 ‘장비의 진짜 최소 간격’**을 분리해야 해. `20, 30, 40kg`만 기록돼 있다면 실제 핀이 5kg인지 10kg인지 알 수 없어. 이웃 차이의 최빈값만으로 확정하는 것은 권하지 않아.

# 확인하지 못한 것과 남은 불확실성

- **공식 × 반복 4구간 × 모든 운동 유형**을 채울 수 있는 통일된 검증 오차 자료는 찾지 못했어. 특히 덤벨과 머신 고립 운동의 빈칸이 커.
- NSCA 원 교재의 2-for-2 해당 페이지를 직접 대조하지는 못했어. 교재를 인용한 공식 교육기관 설명과 ACSM 원문은 확인했어.
- 세트별 독립 진행, 슬라이더 1·2·3회 매핑, 3회 정체·5~6회 조정 기준의 우월성을 입증한 비교시험은 찾지 못했어.
- **고정 5kg만 가능한 가벼운 운동에서는 좁은 반복 범위와 낮은 실패율을 동시에 만족시키기 어려워.** 알고리즘이 해결할 수 없는 장비 제약이야.
- RIR 없이 목표에서 멈춘 기록만으로는 최대 가능 횟수나 실제 1RM을 확정할 수 없어.
- 워치짐의 실제 손목 센서 정확도와 새 진행 규칙의 목표 성공률은 이번 문헌 조사로 확인되지 않았어. 코드 동작은 소스에서 확인했고, 실행·운동 실험은 하지 않았어.
