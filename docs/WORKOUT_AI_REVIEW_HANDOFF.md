  완료 운동/세트의 실제 수행 기록과 손목 분석, 초반/후반 반복 표본, 조건별 수치 비교와 근거 ID를 전달한다.
  구형 세트는 `legacy-*` 조회 ID로 구분하며 원본 저장소를 수정하지 않는다. 카메라 관측은 전달하지 않는다.

  관측/해석 구분, 자료/목표 개수와 길이를 확인한다. 사실 문장의 수치 토큰은 제공 값/소수점 반올림 범위에서 검사한다.
  이는 자연어 의미나 운동 효과 전체의 정답을 증명하는 검사가 아니다. 지표 표시 수치는 앱 원본에서 읽는다.
  목표 수치는 제안으로 구분하고 원본이나 보정 설정을 수정하지 않는다. 개인 기억 제안은 비활성이다.
- `WorkoutReviewController` / `WorkoutReviewStore`: 선택 계정·모델·추론 강도를 고정해 기존 공통 실행기를 사용한다.
  완료된 검증 응답만 저장하고 미완성 미리보기는 표시하지 않는다. 같은 입력/모델/강도/프롬프트는 완료 결과를 재사용한다.
  화면을 나가도 app-scoped 요청은 계속되며 취소·계정/세션 변경·기록 수정에 대한 늦은 결과를 거절한다.
  프로세스 재시작 시 완료 여부가 불명확한 요청은 INTERRUPTED로 표시하고 자동 재호출하지 않는다.
- 기존 완료 결과 화면 하단에 `WorkoutReviewPanel`을 연결했다. 요청/취소, 계정/프로필 연결,

  최초 표시/설정 열기/화면 복귀만으로 모델 추론을 실행하지 않는다.
