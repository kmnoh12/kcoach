# 폰에서 시작하는 운동 흐름 — 사용자 정정 반영

2026-10-15. 디자인/동선 명세이며 앱 구현 완료를 뜻하지 않는다.
이 문서가 이전의 워치 시작 버튼 시안보다 우선한다.

## 워치 대기

앱 실행 직후에는 루틴명, 첫 운동, 시작 버튼을 표시하지 않는다.
폰 연결 전에는 “폰 연결 대기 중”과 고정 폭 점 영역의 . → .. → ... 순환만 표시한다.
실제 연결이 확인되면 “운동 시작 대기 중”으로 바꾸고 점 순환을 유지한다.
연결된 상태를 연결 실패처럼 표시하지 않는다.
폰에서 루틴을 열어도 운동 시작 전에는 워치는 대기를 유지한다.
폰에서 운동 시작 명령을 받으면 D2 운동 화면으로 자동 전환한다. 워치의 추가 시작/확인 탭은 없다.
정상 대기 화면에 설정/업데이트/빈 심박/빈 횟수를 나열하지 않는다.

## 폰의 루틴 화면

어깨전문 선택 → 운동 목록 표시 → 상단의 기존 빈 영역을 현재 루틴 준비 영역으로 사용.
현재 RoutineDetailScreen의 빈 Surface는 높이 285dp인 실제 placeholder다.
준비 영역의 높이는 내용에 맞게 잡고, 빈 공간 채우기를 목적으로 고정 높이를 유지하지 않는다.
연결 상태와 저장된 워치 착용 상태를 요약하고, 변경은 설정의 프로필로 연결한다.
해당 루틴에 포함된 운동만 질문한다. 현재 어깨전문에는 다음 세 후보가 실제 포함돼 있다.

- 케익로(케이블 익스터널 로테이션): 시작 때 손바닥 위 / 전완 수평 방식인지 선택.
- 케리플(케이블 크로스오버 리버스 플라이): 손등 위 그립 방식인지 선택.
- 사레레(덤벨 레터럴 레이즈): 팔을 내린 자세에서 시작하는 방식인지 선택.

각 질문에는 해당 방식, 다른 방식, 모름을 구분하고 처음부터 확인된 것으로 선택하지 않는다.
질문 선택은 수행 방식에 대한 사용자 입력이며 센서 검증 완료를 뜻하지 않는다.
운동 목록/준비 질문을 확인한 뒤 기존 폰 운동 시작 버튼으로 시작한다.
시작을 누른 뒤 착용손/착용면/동일 질문을 다시 묻지 않는다.
다른 루틴은 실제 포함 운동에 맞게 준비 질문이 바뀐다.

## 톱니 → 프로필 설정

기본 신체 정보: 키, 나이, 성별, 몸무게. 체지방률과 골격근량은 선택 입력.
모르는 수치는 빈 값으로 보존하고 임의 기본값/추정값을 넣지 않는다.
워치 기본 착용: 왼손/오른손, 화면이 손등 쪽/손바닥 쪽.
저장된 설정을 새 운동의 시작 조건으로 읽고 세트/세션 시작 시 조건을 고정한다.
운동 도중 설정을 바꿔도 진행 중인 세트의 기존 보정/원본 조건을 덮어쓰지 않는다.
기존 프로필 저장 경로를 확인해 중복 프로필을 새로 만들지 않고 통합한다.
현재 프로필은 ChatGPT 계정 화면에 연결돼 있어, 기본 프로필이 계정 연결 없이 편집 가능한지 함께 정리해야 한다.

## 기존 “본체 위쪽이 향하는 곳”

기술적 의도는 센서가 쓰는 본체 고정 방향이 손 쪽인지 팔꿈치 쪽인지 구분하는 것이다.
UI 화면 회전과 센서 좌표는 다른 값이다. 현재 UI는 원형 본체의 어느 물리 부분을 기준으로 볼지
그림이나 명확한 기기 기준을 주지 않아 사용자가 답하기 어렵다.
일반 운동 준비 질문에서 이 문구를 제거한다.
실제로 이 조건이 필요한 엔진은 설정에서 기기별 식별 가능한 그림/설명으로 설정할 수 있어야 하며,
입력/검증이 없으면 UNKNOWN을 유지한다. 왼손/손등 선택만으로 방향값을 추정 확정하지 않는다.
유효한 방향 조건이 없다는 이유로 운동 전체를 시작 못 하게 만들지 않는다.

## 완료

일반 세트 완료는 휴식으로 전환한다.
폰에서 전체 COMPLETE 명령을 받은 경우에만 운동 완료 화면을 표시한다.
STOP/END를 전체 운동 완료로 오인하지 않는다. 완료 시안의 확인은 대기로 돌아가는 용도다.

## 이번 범위

대기 시안을 수정하고 이 동선 명세를 기록했다. production 소스, 저장 포맷, 통신/인식 엔진은 아직 변경하지 않았다.
워치 START_PREPARED 제안/진입점, 폰 시작 시트, 빈 영역, 프로필 저장/UI는 실제 구현에서 함께 정리할 대상이다.
